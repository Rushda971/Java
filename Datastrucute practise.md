Here are some solid **logical practice questions** on Java **ArrayList** to help you build problem-solving skills—not just syntax.

---

## 🟢 Beginner Level

**1. Reverse an ArrayList**

* Given an `ArrayList<Integer>`, reverse it without using built-in reverse methods.

**2. Find Maximum Element**

* Find the largest number in an `ArrayList<Integer>`.

**3. Remove Duplicates**

* Given an `ArrayList<Integer>`, remove duplicate elements while maintaining order.

**4. Count Even and Odd Numbers**

* Count how many even and odd numbers are in the list.

---

## 🟡 Intermediate Level

**5. Second Largest Element**

* Find the second largest number without sorting the list.

**6. Frequency of Each Element**

* Print how many times each element appears.

**7. Merge Two ArrayLists**

* Merge two lists and return a new list without duplicates.

**8. Rotate ArrayList**

* Rotate elements to the right by `k` steps.

  * Example: `[1,2,3,4,5]`, k=2 → `[4,5,1,2,3]`

---

## 🔵 Advanced Level

**9. Find Missing Number**

* Given numbers from 1 to n with one missing, find the missing number.

**10. Longest Increasing Subsequence (Basic Version)**

* Find the longest increasing contiguous subsequence.

**11. Pair Sum Problem**

* Find all pairs whose sum equals a given target.

**12. Sort Without Using Collections.sort()**

* Implement your own sorting (like bubble sort or selection sort) using `ArrayList`.

---

## 🧠 Bonus Logical Challenges

**13. Palindrome Check**

* Check if the list reads the same forward and backward.

**14. Split Even and Odd Lists**

* Create two separate `ArrayList`s: one for even, one for odd.

**15. Find Common Elements**

* Given two lists, find common elements without duplicates.
